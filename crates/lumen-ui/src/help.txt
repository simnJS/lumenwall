lumen-ui: browse, apply and configure Lumen wallpapers

USAGE:
    lumen-ui                  Open the window
    lumen-ui --tray           Tray icon only (pause, mute, open, quit)
    lumen-ui --background     Start the engine if needed, then the tray icon
                              (what "Start with my session" runs)

DEVELOPER OPTIONS:
    --fake-daemon             Talk to an in-process fake engine (real IPC transport)
    --demo-library            Use a generated library instead of Steam (no Workshop content)
    --page <library|screens|settings>
    --select <text>           Select the first wallpaper whose title contains <text>
    --lang <en|fr>            Language for this run
    --size <W>x<H>            Window size in points
    --screenshot <file.png>   Save the window once loaded, then exit

ENVIRONMENT:
    LUMEN_IPC_ENDPOINT        Daemon socket path (Linux) or pipe name (Windows)
    LUMEN_UI_RENDERER         glow or wgpu
    LUMEN_LOG                 Log filter, e.g. "debug"
    LUMEN_WE_WORKSHOP         Extra Workshop folder (testing)
