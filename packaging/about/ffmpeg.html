Shipped next to lumenwall.exe: ${dlls}. They are FFmpeg ${version}, built by Lumenwall from FFmpeg's unmodified release source with only the demuxers, decoders and hardware decoders that video wallpapers use: LGPL only, no GPL or non-free component, no external library. Lumenwall is a separate work under the MIT or Apache-2.0 license; it loads these libraries by name at run time and never links FFmpeg statically, so you may replace them with another build of FFmpeg ${major} that keeps the same file names.

  • Corresponding source: FFmpeg's release tarball ${source} (SHA-256 ${sha256}), used unmodified, and the script that builds it, ${build_script}. The script downloads the tarball and the two header packages named below, checks their SHA-256, and runs FFmpeg's configure with these options: ${configuration}. Sources, options and toolchain of this build: ${build_info}.
